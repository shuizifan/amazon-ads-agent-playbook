# 搜索词分流、否定范围与迁移验收

适用于报表出现无单高花费、探索活动含优质词、同词多个入口或无效商品目标。保留站点、活动、广告组、主推ASIN、投放目标、匹配、真实搜索词或ASIN、报告周期、点击、花费、广告归因销量/销售额和任务。拆开“用什么参加拍卖”“是什么触发”“在哪里展示”。同一搜索词可来自多个入口，精准匹配仍需看触发的近似表达。来源为第04册第112–122页。

## 决定该放大、观察还是止损

| 真实流量情况 | 核查 | 可执行的下一步 |
|---|---|---|
| 产品事实不符、型号不兼容、使用需求明显错位 | 核实搜索词的限定条件及商品事实；查同根是否还有能成交的长尾 | 对具体无效词或ASIN用小范围排除。若整条词组方向反复证实无效，再扩大范围。 |
| 相关、样本少或归因未成熟 | 对比该产品正常CVR、累计花费和单笔可承受广告费；标注促销、断货、改价或改图 | 在可承受预算内继续采样，或较低竞价观察；极小样本单次出单也先留观。 |
| 相关但多次点击无单 | 按真实搜索意图、具体广告位、竞价、价格、主图、配送和评论查异常，区分个别流量与整页普遍差 | 高CPC降价，方向过宽收窄，页面有问题优先改页；达到经济止损线且根因未修时暂停或否定。 |
| 稳定有单且成本合适 | 验相关、重复订单、利润、可拓搜索量和任务 | 精准承接有效搜索词，词组延展一类明确需求，手动商品投放承接重复转化ASIN。核心词可独立预算，页面同步补充真实购买理由。 |
| 多单但ACOS偏高 | 分解CPC、CVR、客单和位置；查能否低价保住有利润订单 | 测降目标竞价或低效位置加价，对跑偏词单独清理；已有重复价值的流量不因一项均值全部关掉。 |
| 排名、品牌防守等战略词 | 记录该词承担的任务、观察期限和能承受的投入 | 单列活动、预算及退出条件，另核排名、自然订单或品牌流量；任务完成后重估投入。 |

**样本与止损。** 期望每单所需点击≈1÷CVR。该数字只反映均值。经济参考点击数≈单笔可承受广告成本÷平均CPC。达到该值触发复查，不能推出下一次一定出单或应自动否定。高量目标可用较短周期发现异常，低量则延长窗口；两者均须给归因留出时间。来源为第04册第122–135、151–152页。

**混合流量的核查。** 按真实搜索词分别汇总花费和广告归因销售额，再与活动总计核对。整体ACOS较高仍可能含有能获利的词，整体达标也可能含有无效方向。按意图和利润提取好词，单独清理无效词，保留探索入口。来源为第04册第119、135–136页。

## 选择否定的对象、类型和层级

- **否定精准**适合具体无效搜索词，或者将一个已稳定承接的好词从来源分流。教材正文包括系统识别的近似变体。更长或不同表达仍可能进入，随报表验证。第04册第137–139页。
- **否定词组**适合整条购买方向长期无效，例如商品完全不适用的型号或用途。先搜索该词组在历史报告中带来的全部长尾和订单。按实际词组与匹配规则检查可能受影响的查询，再用生效后的报告核验；词义相近不足以断定会被一起排除。参见第04册第139–141页。
- **否定商品或品牌**先查需求、规格、兼容、价格、评价与长期成本。在一个品牌内只要部分ASIN无效，优先排具体ASIN；跨价格带及产品范围均显示无效才考虑品牌层排除，并保留日后恢复依据。第04册第145–146页。
- **广告组级与活动级**按实际作用范围选择。A组不适用、B组能成交时只处理A组；活动内各组都不适用才考虑活动级。若整个投放目标已无价值，可暂停该目标；其中有优有劣则保目标、排坏词。第04册第136–137、143–146页。

## 好词迁移的先后顺序

1. 在自动、广泛、词组或商品目标报告中核实实际来源。若来源只是偶发一单、搜索量太小、原活动稳定且新活动无预算，暂保留原路径。第04册第125–129、147–150页。
2. 把已验证的搜索词放入能独立控制的精准目标，设置与历史CPC、目标ACOS相符的基础价与预算。ASIN则建手动商品目标。确认新路径实际有资格、有展示、取得点击，并具备承接能力。第04册第126–128、147–148页；第07册第126–135页。
3. 需要集中数据或预算时，在原来源添加否定精准。只处理要分流的词和组，不在精准承接端屏蔽自身。核同词跨入口的总展示、总订单、花费和利润，避免仅看新活动上升、实际总量下滑。第04册第128、147–150页。
4. 建否定记录，含搜索词/ASIN、类型、添加层级、日期、当时点击/花费/订单/ACOS及原因。复查成交、浪费和误伤，产品升级、竞争或季节变化时可重新小测。第04册第152–158页。
