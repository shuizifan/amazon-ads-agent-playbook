# 媒体规划与站外引流衡量

用于回答投放前怎样比较方案、投放后怎样衡量站外流量。规划用的预测、引流洞察的归因销售与经营净利属于三个不同结果。资料版本为 2026 年 7 月，市场覆盖、账号权限、费用、标签能力和归因窗口以站点及账户当期说明为准。

## 用 Ads Planner 比较预算方案

先定一项主要业务目标和一项辅助目标：触达尚未认识品牌的人、让考虑者进详情/加购、在利润范围内获取新订单，或按复购周期留住老客。明确站点、人群、商品/品牌范围、起止日、总预算、毛利与现金流、库存覆盖、促销、素材及历史基线。全盘预算还要分到市场、商品、日期和活动；不能直接拿总额当单活动日预算。先查管理账户、权限和支持市场。【06 册 P4–25】

| 决策 | 判断方法 |
|---|---|
| 选工具或范围 | Ads Planner 比较整体格式、人群和预算；Channel Planner 深入某个渠道的覆盖、频次和成本；规划 API 用于规模化接入。单格式计划可检验一个渠道，多格式计划可估算交叉覆盖，全漏斗计划需明确各阶段任务 |
| 候选方案 | 在相同目标、周期、商品与总预算下，分别比较搜索承接、搜索＋展示、视频/流媒体＋展示＋搜索等组合。SP 承接明确需求，SB/Store 提供品牌和系列入口，展示可做发现或再营销，视频/流媒体扩认知。资格和创意决定实际可选项 |
| 读触达与频次 | 展示量是次数，触达用独立人数，平均频次＝总展示÷独立触达。两渠道的合计去重触达＝A 触达＋B 触达−同时触达。低触达高频先看是否集中于再营销，高触达低频查能否建立记忆，高触达高频校验新增价值和成本，双低查预算、人群与可投性 |
| 决定是否继续加预算 | 在触达曲线上比较每一档新增预算带来的新增去重触达。斜率减小时查重复展示、弱相关人群、昂贵位置；再营销还要看购买与利润。预估结果按历史模型产生，须再经过毛利、退货、库存、现金流与素材供应检验 |
| 执行与回看 | 将方案明确到活动、商品、定向、竞价、预算、创意、落地；预算规则属于后续执行。逐项对比预计和实际花费、去重人数、频次、格式占比及核心 KPI，记录断货、竞价、价格、促销和需求变化 |

来源：06 册 P8–43、P47–66。P34 图右侧文字与纵轴位置冲突，以上使用明确的高低组合解释。

新品按评论、库存、详情和可用素材选择小范围验证或扩大组合；增长期用已验证的搜索词、ASIN、受众及素材确定新增预算；成熟期优先查重叠与净新增；大促前积累触达，促中保证搜索、防守与再营销承接，促后分别跟进未购和复购。实际花费低，先查竞价、范围、商品资格、购物车及落地；实际频次偏高，查多活动重叠、周期过短、受众过窄及素材疲劳；触达高而转化弱，沿受众→创意→落地→价格/评价→下层搜索查。转化好而新增触达少，排查是否过度依赖已有品牌词或再营销。【06 册 P30–39、P42–66】

## 用 Amazon Attribution 给站外来源分账

**建标签。** 先写出想单独调整的渠道、发布者、创作者、素材或落地页，再设计活动→广告组→标签的层级。邮件与社媒属于渠道，具体平台属于发布者，一个创作者或一种素材可独立标记。明确单品/优惠送对应详情页，场景或多商品送匹配的 Store 子页。少量手建，大量用支持的导入。先试链接跳转是否保留完整标签、目标 ASIN 和移动端页面是否正确，发布后查点击。重复使用标签、重定向截断或同一入口混用标签会削弱可解释性。【06 册 P67–77、P90–96】

**选报告。** 效果报告看趋势，渠道/发布者报告比较来源，关键词/创意报告比较内容，商品报告区分推广 ASIN 与同品牌其他商品的光环。总计可能已含推广品与光环，不重复加总。资料的最后点击示例在 14 天窗口内把一次购买计给最后符合条件的站外点击；与 Store Insights、站外平台或站内广告报表对数时，先核日期时区、去重过滤、跳转、窗口及活动定义。一个订单可以出现在不同测量体系，汇总归因销售不能直接代表新增销售。【06 册 P75–82、P95–100】

| 漏斗现象 | 优先检查与行动 |
|---|---|
| 点击多，详情页浏览少 | 查标签、跨域或多次跳转、预览或机器人点击、移动端可用性、站外承诺与目的页 |
| 浏览多，加购少 | 复核价格、优惠、主副图、评论、变体和配送，比较落到不同 ASIN 的表现 |
| 加购多，购买少 | 查最终价格、优惠有没有生效、缺货、配送、结账阻力与替代品 |
| 购买量尚可，销售额低 | 核购买的是低价 SKU、折扣过深、件单量低还是客单下降，计算实际毛利 |
| 推广品弱、光环强，或新客多、ROAS 一般 | 明确实际购买商品、受众真实需求与下轮主推；有复购/交叉销售证据时再测长期价值。小样本高购买率先复验 |

来源：06 册 P78–93。

**预算和利润。** 将站外成本与同标签、同期间的归因结果对应。站外 ROAS＝归因销售额÷站外花费，站外成本率＝站外花费÷归因销售额；每次购买成本（CPA）＝站外总投入÷归因购买量。新客获客成本（CAC）＝对应的获客投入÷去重新增买家数；若数据只有品牌新客订单，所得应标作每笔品牌新客订单成本。另列媒体费、创作者费、样品、佣金、素材、服务费，再按实际口径扣产品、平台、履约、折扣和退货，已体现在净销售的折扣或已含供应商报价的费用不重复扣。品牌推荐奖励需核资格、比例、最终结算与退货，待确认金额不能直接冲减成本。扩量时保持时期、商品、优惠和落地可比，按新增预算带来的新增获客/购买成本复查，再决定放大、留测或暂停。【06 册 P87–106】
