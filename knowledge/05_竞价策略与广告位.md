# 竞价策略、广告位和受众如何一起诊断

适用于CPC意外上涨、顶部占比变化、想争取排名或比较企业买家受众时。先取活动任务、商品与目标明细、匹配方式、基础价来源、各加价设置与变更时间、分位置表现、实际CPC、CVR、花费、广告归因总销售额和库存。来源为第04册第56–60、96–108、164–166、188–191页。

## 从一次展示解释一组报表

关键词、ASIN、品类或自动组决定竞拍哪些流量，位置描述展示在哪里，企业购买和受众描述面对谁。某个ASIN目标既可能在搜索结果也可能在商品页展示。一位企业买家在顶部下单，同时属于高购买可能性受众，这笔订单可以被三个标签记录。用活动总计核订单，以分层报表比较效率，避免相加。来源为第04册第57–59、75–79、91–98页。

| 已观察到的机会 | 可测试的条件 | 复查什么 |
|---|---|---|
| 搜索顶部争取核心词 | 意图明确、词已转化、页面在价格评分主图上能竞争；目标有额外展示空间 | CPC和新增单成本、转化、位置占比及利润；加价只增加争取机会。 |
| 其余搜索结果出现低价出单 | 有可重复的长尾或比较型搜索词，可控制探索价格 | CPC低的同时，订单和利润是否稳定。 |
| 商品页截流、配件推荐或自有防守 | 竞品规格、数量、价格或评价可比较；关联商品确有搭配理由 | 搜索词/ASIN行、转化及回报。单个ASIN差先处理该目标。 |
| 企业买家流量 | 多件装、标准化规格、可重复采购、可稳定补货；页面说明件数与单位经济 | 流量规模、CVR、件单量、客单价、ACOS/ROAS和具体ASIN，区分大额偶发单。 |
| 行为受众流量 | 购买可能性高用于相关探索，点击/加购用于找回，已购用于补充装、配件、升级或复购 | 与同窗口同任务的受众内外表现对比，看规模、CPC增幅、转化及客单价值。耐用品短期重复购买需求弱时考虑配件。 |

同一活动、商品、匹配方式与时间内比较位置；目标分工不同应分别评估。位置加价0%表示保持基础出价。只考虑一个位置调整时，该位置的出价=基础竞价×（1+该位置加幅）。三种普通位置分别计算。命中额外身份/策略时，以当期后台实际配置判断；跨维度规则不能套入统一乘法。原资料中的最高加幅用于解释机制，具体可用范围见对应账户。来源为第04册第59–80、84–98、189页。

## 按活动任务选竞价策略

| 当前任务 | 候选策略 | 成立条件与风险 |
|---|---|---|
| 新品、小预算或宽流量探索 | 动态竞价仅降低 | 预估转化较差时可降低策略层出价。基础价、位置、企业或受众调整仍能抬高最终竞争上限；CPC高先查这些设置和流量构成。 |
| 品牌词、自有ASIN防守、分离变量测试 | 固定竞价 | 策略层不根据实时转化预测升降，人工管理基础和位置。实际CPC受竞争变化影响，弱机会也不会因该策略自动降价。 |
| 已验证的核心精准、优质ASIN或大促主力 | 动态竞价提高和降低 | 要有重复订单、可承受的更高CPC和库存预算。看花费增速与新增订单、顶部成本和全天预算覆盖；转化没有改善而成本升高，可回到保守策略。 |
| 成熟SP活动，目标清楚且后台有资格 | 基于规则的竞价 | 面向整个活动设定目标ROAS，系统调整基础竞价。源文要求关注近期转化、运行时间、预算和站点资格，具体门槛按账户。按较长周期核整体ROAS、订单量和利润。 |

同一口径下目标ROAS=1÷目标ACOS（ACOS用小数）。活动整体按广告归因总销售额÷总花费计算，不能简单平均各词ROAS。目标过严会压缩量，过松可能挤占利润。活动级目标ROAS与卖家编写的条件调价规则要分清，预算规则处理活动支出空间。来源为第04册第166–187、190–200页。

## 症状与动作

- **顶部CPC升、转化和新增订单同步提升。** 核算新增单成本、可承受利润与库存；若可持续，保留或小步试量。若高价只替换了原有较便宜的点击，则回调。第04册第62–65、103–106、175–177页。
- **CTR高、CVR低。** 先按词和ASIN查看流量意图，核价格、评价、优惠、规格及配送；意图正确而多个位置都失速，优先修页面。若同一目标仅在特定位置差，调整相应位置。第04册第70–75、103–105页。
- **企业或受众订单少、销售额高。** 查单笔件数、客单与样本稳定性。若购买方大额订单可重复且库存能接，再启动一项小幅调整。不同标签的订单要去重。第04册第80–82、91–97页。
- **活动CPC突然拉升。** 对照变更时间检查基础价、位置、Business和受众设置、动态策略，再看预算提前耗尽、价格与优惠、库存和评价、竞争及归因。固定竞价或仅降低都可能出现高实际CPC。第04册第104–108、188–191页。
- **需单独控顶部或商品页。** 确认跨周期差异稳定、点击量够且独立预算可支持取样；订单稀少、差异不稳定或预算太小，留在原结构积累。第04册第106–108页。
- **切换策略。** 记录原设置及同日型基线，每轮改变一个变量。大促先写恢复日期，观察数据成熟后的新增花费、订单、利润，再决定保留或回调。较强的转化证据、预算和库存一起支持提强度；页面变弱、促销终止、顶部失控、预算过早耗尽应重新评估。第04册第192–198页。
