# 品牌内容、创作者合作与旗舰店

用于判断如何获得创作者推荐、采购可投放素材、统一品牌身份，以及把搜索或站外流量送到合适页面。资料为 2026 年 7 月版，涉及资格、费用、佣金门槛、授权期、规格和归因窗口，执行前以站点、账户当期页面和合同为准。

## 先决定买什么

| 当前任务 | 工具与输入 | 观察什么 |
|---|---|---|
| 想让创作者推荐特定商品，以合格成交支付额外佣金 | Creator Connections 的 Affiliate+。准备一组受众和使用场景相近的 ASIN、活动期、佣金比例与预算上限、优惠、库存、卖点及禁语 | 从参与、实际发布和访问追到合格订单、退货后销售、额外佣金及净贡献 |
| 需要可用于站内广告的视频或图片 | Sponsored Content Requests。先确定用途、格式、ASIN、创作者、固定制作费、交付及审核要求，再明确投放范围和到期日 | 接受率、提交、修改、批准、授权入库与后续广告数据分开看 |
| 素材已经有人发布 | 从 Licensed content 核实品牌是否拥有相应用途，核准授权的商品、格式、市场、平台、期限、剪辑权和续期安排后再调用 | 原帖存在或已付佣金都不能证明品牌拥有投放权 |
| 目标是积累真实商品评价 | 单独核对应站 Vine 资格。Influencer Program 属于创作者身份、Storefront 和联盟变现体系 | 禁止把活动报酬与五星评价、特定评价倾向绑定 |

来源：05 册 P4–15、P21–33。

### 佣金、固定费和媒体费分别核算

- 每单佣金承受额＝预计净成交额−商品、平台、履约、折扣及退货成本−目标利润。可承受额除以佣金计算基数得到佣金率上限，折扣是否已体现在净成交额要对账。活动佣金预算是上限，最终确认归因、取消和退货会影响结算。【05 册 P9–13】
- 给每个活动一个主题。创作者说明写目标人群、要解决的问题、约三个卖点、必演场景、优惠与时间、需要披露及禁止主张的内容，让创作者用自己的语言讲。先筛类目、类似内容、解释能力、受众购买意图；进活动人数多而实际发布少要排查报酬与匹配度，访问多而购买少先回查页面、价格与库存。【05 册 P13–21】
- 佣金效率＝额外佣金÷合作计划归因销售额。另建广告放大时，标准 ACOS＝广告花费÷广告归因总销售额。另行评估同一批素材的含制作费成本率时，用（归属该批的广告费＋分摊制作费）÷该批广告归因总销售额。注明费用分摊方式，并另核样品、授权续期及产品费用。【05 册 P18–20、P31–35】
- 固定内容请求应具体约定镜头、交付格式、修改机会、审核和授权。反馈应指向哪一秒、哪个配件、哪句声明或哪种裁切有问题。授权内容入库后仍需另建广告和媒体预算。资料列举初始授权 90 天、每次最多 3 个 ASIN 和 5 名创作者，均须以当期条款和账户创建页确认。【05 册 P21–31】
- 测素材时保持 ASIN、受众/关键词、竞价、预算、位置及落地基本一致，比较次数充足的点击、成交、新客与投产。站外帖子可能带来带标直购、品牌搜索或再营销订单；分别查看路径，跨报表相加会高估销售。新品先测可演示的场景，增长期放大获准使用的有效内容，成熟期核授权续期和季节迭代。高退货、库存不足或页面尚未能解释产品时，先修承接。【05 册 P29–43】

## 品牌名称、Logo 或介绍不一致

品牌注册关系决定资格，Brand Profiles 保存顾客可见的品牌名、标识、介绍、视觉和关联，Store 负责组织页面，广告负责购买流量。先核站点、品牌归属及用户权限，再核卖家账号名是否被误用为品牌名。把展示名称逐项对照商标、包装、Listing、Store、广告与官网，避免未经核准自加 Official、促销词或联系方式。【05 册 P44–50、P56–61】

用真实价值与证据写介绍，准备完整标识及可缩小辨认的版本，核留白、移动端、品牌色与素材商用权。维护标准名、徽标、介绍、版本日期、素材来源、授权范围到期日，供运营、广告和设计共用。更新后逐一打开已有广告、店铺和品牌内容确认展示结果。档案本身没有独立的 ACOS，可用素材实验及搜索、Store 访问或新客趋势辅助判断下游表现。【05 册 P50–66】

## 旗舰店页面和来源怎么选

| 流量意图 | 落地及信息顺序 |
|---|---|
| 品牌词或首次认识品牌 | 首页首屏写清是谁、卖什么和分类入口，突出当前重点并给明确选购路径 |
| 品类、场景或人群需求 | 分类或场景子页只解决一个选购任务，先讲相关差异，再用网格或可购物图导向对应商品 |
| 明确颜色、规格、套装或特定 ASIN | 如无系列比较需求，直达精确子体详情页；让顾客自行挑变体才用父 ASIN 入口 |
| 创作者、邮件、官网、包装或活动 | 为可独立调整的来源建立标签，跳到与内容承诺一致的子页或详情页。用到站、浏览、订单、销售比较来源 |
| 大促、季节或跨站 | 预留审核时间并准备活动后恢复版本。核本站语言、文字、可售 ASIN、价格与促销有效期，逐页复查 |

来源：05 册 P67–89、P96–103。

店铺建设从选站点和品牌、准备素材、画导航、选模板、填充页面，到移动与桌面预览、审核、发布。页面任务决定用主视觉分类、商品重点、商品集合或空白模板。商品网格适合系列选购，独立模块适合重点讲一件商品。场景图片仅标真正出现的商品。图例写品牌徽标常见 400×400、可购物图最多 6 个 ASIN，应查当期 Builder。教程、操作细节用可主动观看的视频，氛围内容可用背景视频；页面太长、文字太小、标题裁掉或首屏导航不可点，应先修再引流。【05 册 P73–87】

Store Insights 中，Visitors 看独立访客，Visits 看访问次数，100 位访客加 20 次回访对应约 120 次访问。把来源、落地页、浏览深度、停留、退出与订单关联阅读；一次访问完成购买也是正常路径，多页浏览也可能是找不到商品。高流量低销售查主推和页面，低流量高效率可试加入口，子页优于首页可直达。图中订单、件数与销售属估算归因（示例 14 天）；店铺质量评级和流量规模均不能替代利润。遇上架、断货、换主推、大促和数据异常及时复查；拒审查动态价格、无依据效果、过期促销、空页及外链。【05 册 P88–103】

## 需要图片、视频、音频或本地化素材

1. **需求与素材库。** 把实际搜索词、商品定位及受众疑虑翻成可见画面。例如购买者担心尺寸就给同尺度对照，关心做法就演示操作。以站点、品牌、ASIN、场景、格式、日期及版本定位文件，按长期、活动、测试、授权分类，保留无字母版和中央安全区。每个广告/店铺版位另核规格、授权与审核。【05 册 P104–115、P158–164、P172–180】
2. **选工具。** 图像生成器可围绕真实商品生成场景，提示交代环境、主体位置、光线、周边及风格；修图用于裁切和校色。视频模板复用已有图、徽标、短文案和音乐；生成器可从商品、静图或长片生成候选视频，静图动画每次只动一个元素，视频摘要需复核镜头顺序及二剪权。Creative Studio 将调研、故事板、图片、视频、文案、配音和素材库串起来，独立工具适合单项任务。Creative Agent 的初稿需人工确认。【05 册 P114–123、P130–153】
3. **上线检查。** 逐项核结构、数量、比例、包装文字、配件、物理用法、人物细节、虚构功能、声明证据、版权、移动端裁切。精密安装、受监管商品、色差和套装数量优先保留实拍证据。视频前三秒应看见商品，静音能看懂，核镜头一致、字幕、音乐授权、结尾行动。音频核发音、语速、无画面能理解、背景音乐不压人声。译稿核本地用词、单位、声明、屏幕字与字幕同步；搜索词本地化另做。【05 册 P123–144、P152–165】
4. **投放验证。** 保持商品、预算、竞价、定向和落地一致，一轮只改一个主要变量。曝光高点击低查画面与意图，点击高转化低查承诺与落地，完播高少点击查行动理由，开头流失优先换开场。按格式、位置和样本比较，记录版本及下轮动作。拒审先读具体理由，再查素材、文案、落地、授权和类目。【05 册 P165–180】
