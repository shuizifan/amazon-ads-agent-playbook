# 根据商品、推广任务和证据选择推广节奏

先判买家为什么会下单，再判当前缺的是流量、点击、转化、供货或利润。相同上架天数可能对应不同阶段。启动前记录广告/自然订单、广告及自然位置、页面访问和转化、价格优惠、评分评价、库存和日销量，避免把促销、季节或改版误归因为广告。来源为第07册第5–18、42–46、81–90页。

## 先判断购买决策

| 买家判断依据 | 页面与流量设计 | 点击后不买怎么查 |
|---|---|---|
| 标品重型号、规格、兼容 | 用型号、接口、尺寸、数量与用途明确的词；主图和标题帮助买家快速识别，副图交代适配与限制。商品投放挑可替代且有竞争力的ASIN。 | 查是否买错型号、单位或套装；再比同规格产品的价格、评价和配送。 |
| 非标品重风格、场景、人群偏好 | 用风格、颜色、尺寸、使用空间等真实表达组合流量；用主图、视频和场景说明产品在实际环境中的样子。比较买家偏好重叠的竞品。 | 查广告素材与落地页风格是否一致、变体有无断货，以及评价和退货原因是否提示实物与想象有落差。 |
| 半标品兼具规格和偏好 | 将硬性适配和可选风格分别写入页面，按两种意图分别取样 | 先排除规格不符，再看是否偏好表达不足。 |

分类证据可来自实际搜索词、参数筛选能否迅速排除商品、买家在竞品页比较什么、评论和退货理由、品牌溢价与可替代性。价格高通常需要更长决策和更多信任证据；低客单要更严控CPC。跨站点检索要查看目标站点的联想词、竞品页、本地评论和真实广告报告。来源为第07册第14–36、110、164–169页。

## 新品阶段如何决定是否进入下一步

| 推进条件 | 该阶段要回答的问题 | 继续、扩大或止损的条件 |
|---|---|---|
| 上线准备 | 产品能否卖、页面有无购物车和配送、利润及库存能承接多少 | 列核心/属性/场景词和候选ASIN，记录初始页面、排名、预算和止损。库存覆盖天数≈当前可售库存÷推广后预计日销量，与补货运输、上架和安全库存对照。 |
| 开始投放 | 活动是否健康、系统理解的产品类别是否正确 | 低展示先查资格、状态、相关性、竞价和预算；先修基础故障。 |
| 已有一批真实流量 | 买到哪些真实查询和目标页，买家是否愿意点击 | 看搜索词、ASIN、位置、主图价格与CTR。排掉明显不相关目标，相关小样本继续取样。 |
| 形成可评样本 | 是否出现可重复的订单路径 | 成交集中在真实词或ASIN时标记并小范围迁移；流量相关但多方向持续低转化，先修详情页、评价、价格或配送。 |
| 出现重复订单或接近止损 | 放大后有无新增有价值订单 | 转化可复现、单位经济合适、库存和预算够，再提高已验证目标的竞价或单独供给预算。多方向试验均失败且已达止损，降速、修复或退出。 |
| 有效路径持续稳定 | 订单能否由清晰结构支撑 | 精准与优质ASIN承担稳定单；保留低成本探索，按需要加入品牌、受众。继续看利润、自然单与核心词位置。 |

原PDF第55页给出日历示例，进入下一阶段以归因成熟、样本积累和任务完成度为准。强季节商品另设预热、峰值、回收窗口。供应紧张时缩小放量目标，保留核心验证或利润流量。来源为第07册第45–58、84–96、106–115页。

**新品结构和预算。** 先判断需求通过哪些入口产生。高意向查询已知时，可用精准或词组验证；查询分散、表达未知时，可让自动或广泛承担发现；消费者主要在可比商品间选择时，可优先验证一小组商品目标。具备相应资格、素材和流量后，再评估品牌视频、商品集或再营销。预算有限时，优先保留最有依据、能获得可评样本的入口，并约定该方向累计测试上限。同一类商品也可能因站点、查询意图、阶段及单位经济不同而选择不同结构。来源为第07册第46–50、87–90页。

## 老品先判状态，再拆订单下滑原因

稳定盈利型保核心利润和防守；仍成长型对重复出单的词、ASIN和位置逐项扩量；衰退型先判需求仍在及页面是否落后；季节型对齐去年同期及预热、峰值、回收阶段；修复后重新激活型以少量已知高相关目标验证。成熟预算可向利润核心倾斜，同时给新词、新商品、受众和素材留出试验空间。来源为第07册第59–67、102–110页。

| 下滑所处环节 | 证据和行动 |
|---|---|
| 展示降，其他指标相对稳 | 查市场需求、自然及广告位置、预算覆盖、资格、库存和竞价，区分需求减少与竞争份额下降。 |
| 展示稳、CTR降 | 比较前台主图、价格、优惠、评分、竞品新品和展示位置；再决定是否改素材或调位。 |
| 点击稳、CVR降 | 查看最近差评、页面版本、价格、配送、缺货变体与竞品升级，修复后用同类目标小规模重测。 |
| CPC涨、订单未跟上 | 重算可承受CPC，按位置和目标查花费，寻找可获利的长尾或商品页流量。 |
| 广告销售稳/升而总销售降/不变 | 查自然关键词位置、自然单、总销售额、利润、广告费占总销售额及类目需求。可能是自然流量变弱或替代，单看广告归因不足以确认因果。 |

广告订单在同一口径下可近似拆成展示×CTR×广告CVR。若商品和竞品需求都在收缩，单靠提价争位未必挽回销量。库存、价格或差评问题解决前，避免用额外预算掩盖转化下滑。来源为第07册第67–70、96–106页。
