# 亚马逊广告 Agent 手册

面向亚马逊广告运营人员和协助其工作的 Agent。知识库解释指标、广告结构和诊断方法，执行手册把这些知识用于活动识别、数据分析、调整和复盘。

| 任务 | 入口 |
|---|---|
| 查广告结构、预算、归因、利润、排名或品牌广告 | [知识库索引与 13 个主题模块](knowledge/README.md) |
| 接管广告，判断是否调价、调预算、迁词或否词 | [广告托管执行 SOP](sop/managed-ads.md) |

## 给 Agent 使用

将 `knowledge/` 导入检索知识库。需要执行托管工作时，另加载 `sop/managed-ads.md`，在私有工作区配置实际站点、产品、经营目标、数据源以及允许执行的动作。仓库提供文档，实际取数和写入取决于运行环境的连接与授权。

例如，遇到“自然排名靠前，是否值得降低广告竞价”，先在知识库查看第 05 篇的广告位口径和第 13 篇的利润验证，再按 SOP 的调价表选择对象，记录基线、授权方向和复查窗口。仓库中的商品名称及数值算例仅用于说明方法。

## 项目维护

概念和指标定义更新到对应知识模块；执行条件、频率和验收步骤更新到 SOP。新增主题时同步更新知识库索引。店铺导出、运行日志、真实商品映射及访问凭据保存在私有工作区。

知识文档整理自广告课程资料并补充了运营方法。保留的卷页注记用于追溯；课程原件、截图与逐图记录另行保管。
